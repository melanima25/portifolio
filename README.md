# Portfólio — Breno Ferreira

Código da minha landing page de portfólio de desenvolvedor júnior, publicada em https://portifolio.brenojf19.workers.dev

A página reúne os projetos que construí, cada um com demo e código: o CRM de um lava jato (em produção), um dashboard de indicadores, um CRM para escritório de advocacia e um chatbot com IA que só responde com base nos documentos do negócio. Os projetos de demonstração usam **dados 100% fictícios**.

## Onde está cada coisa

- [`site/`](site/): o site (Astro + TypeScript + Tailwind, com uma única ilha React). Como rodar e a estrutura estão em [`site/README.md`](site/README.md).
- [`docs/ARQUITETURA.md`](docs/ARQUITETURA.md): decisões de arquitetura, tokens de design e checklists de acessibilidade e desempenho.
- [`docs/relatorio-mercado-portfolio.md`](docs/relatorio-mercado-portfolio.md): a pesquisa de mercado que orientou a escolha dos projetos.

## Como rodar

```bash
cd site
npm install
npm run dev
```

## Como usei IA

O site foi construído com apoio de agentes de IA, e eu revisei cada entrega. Decisões e justificativas ficam nos documentos de `docs/`.
